# Контент-план Logsy

Статьи для привлечения трафика, сгруппированные по направлениям. Каждая статья
опирается на реальную реализацию из репозитория (ссылки на модули указаны внутри).

## Целевая аудитория

- **Соло-разработчики и фрилансеры** — ведут несколько клиентских сайтов, боятся
  узнать о падении позже клиента.
- **Небольшие веб-студии и агентства** — держат на поддержке десятки проектов,
  отвечают за SLA перед клиентами.
- **Основатели малого онлайн-бизнеса без техотдела** — нужен принцип «упало →
  пришло письмо/телега».
- **Продуктовые стартап-команды 1–5 человек** — нужен дешёвый логгинг фронт-ошибок
  и uptime без внедрения Sentry + Datadog.

Гео — РФ и СНГ: оплата в рублях, чек по 54-ФЗ, вход через Яндекс ID, алерты в
Telegram, RDAP/WHOIS по российским TLD.

## Как использовать

1. Технические статьи (1, 2) — публиковать на Habr от лица разработчика,
   кросс-постить анонсы в Telegram. Дают ссылки и приводят ядро ЦА.
2. Импортозамещение (3) и боли (4) — SEO-лендинги/статьи под запросы «аналог
   Pingdom», «мониторинг SSL», «уведомление о падении сайта в Telegram».
3. Кейс для студий (5) — на VC.ru и в профильные сообщества, под партнёрскую
   программу.

Во всех статьях CTA — регистрация на бесплатном тарифе (300 сессий/сутки,
мониторинг без ограничения по времени).
